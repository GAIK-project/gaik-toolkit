For business value evaluation, the toolkit includes a **value evaluation framework**. Rather than focusing only on technical metrics, this framework supports a broader assessment of how GenAI changes work, decisions, and experiences.

It helps organizations evaluate different value dimensions—such as informational, economic, operational, and experiential value—and supports structured discussions about where and how GenAI creates meaningful benefits.

---

## Value Dimensions

- **Informational value** — better access to, and quality of, the information people work with.
- **Economic value** — cost savings, time savings, and revenue impact.
- **Operational value** — faster, smoother, or more reliable processes.
- **Experiential value** — improvements to the experience of employees and customers.
