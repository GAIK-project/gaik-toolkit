## Software Modules

Software modules are higher-level, end-to-end pipelines that combine software
components for common workflows.

### Audio-to-Structured-Data

End-to-end pipeline that combines transcription and extraction to convert audio
or video input into structured output.

- **Implementation code**: [implementation_layer/src/gaik/software_modules/audio_to_structured_data](https://github.com/GAIK-project/gaik-toolkit/tree/main/implementation_layer/src/gaik/software_modules/audio_to_structured_data)
- **Usage examples**: [implementation_layer/examples/software_modules/audio_to_structured_data](https://github.com/GAIK-project/gaik-toolkit/tree/main/implementation_layer/examples/software_modules/audio_to_structured_data)

### Document-to-Structured-Data

End-to-end pipeline that combines document parsing and extraction to convert
documents into structured output.

- **Implementation code**: [implementation_layer/src/gaik/software_modules/documents_to_structured_data](https://github.com/GAIK-project/gaik-toolkit/tree/main/implementation_layer/src/gaik/software_modules/documents_to_structured_data)
- **Usage examples**: [implementation_layer/examples/software_modules/documents_to_structured_data](https://github.com/GAIK-project/gaik-toolkit/tree/main/implementation_layer/examples/software_modules/documents_to_structured_data)

### Typical Usage

Use software modules when you need:

- faster delivery with standard workflows
- less orchestration code
- consistent pipeline behavior across projects
