## Overview

The AudioToStructuredData pipeline combines audio transcription with structured data extraction. Transcribe recordings and extract specific information using natural language requirements - all in one step.

## Quick Start

```python
from gaik.software_modules.audio_to_structured_data import AudioToStructuredData
from pathlib import Path

# Create pipeline
pipeline = AudioToStructuredData(use_azure=True)

# Process audio and extract data
result = pipeline.run(
    file_path=Path("meeting.mp3"),
    user_requirements="""
    Extract meeting information:
    - participants: List of attendee names
    - decisions: Key decisions made
    - action_items: Tasks with owners
    - next_meeting: Follow-up date if mentioned
    """
)

print(result.extracted_fields)
```

## How It Works

The pipeline combines two software components:

1. **[Transcriber](/toolkit/transcriber)** - Converts audio/video to text using Whisper
2. **[Extractor](/toolkit/knowledge-extraction)** - Extracts structured data using GPT

```
Audio/Video → Whisper → Transcript → Schema Generation → Data Extraction → Structured JSON
```

## API Reference

### AudioToStructuredData

```python
from gaik.software_modules.audio_to_structured_data import AudioToStructuredData

pipeline = AudioToStructuredData(
    use_azure=True,           # Use Azure OpenAI (or False for standard OpenAI)
    compress_audio=True,      # Compress large audio files
    enhanced_transcript=True  # Use GPT-enhanced transcription
)
```

### run()

```python
result = pipeline.run(
    file_path=Path("audio.mp3"),   # Path to audio/video file
    user_requirements="...",        # Natural language extraction requirements
    custom_context=""               # Optional context for transcription
)
```

### AudioToStructuredDataResult

```python
result.transcript           # Raw transcript text
result.enhanced_transcript  # GPT-enhanced transcript (if enabled)
result.extraction_model     # Generated Pydantic schema
result.extracted_fields     # Extracted data as dict
result.item_requirements    # Field-level requirements used

# Save all outputs
result.save("output/")
```

## Use Cases

### Meeting Notes

```python
result = pipeline.run(
    file_path=Path("standup.mp3"),
    user_requirements="""
    Extract standup meeting data:
    - date: Meeting date
    - attendees: List of participants
    - updates: What each person shared
    - blockers: Any issues mentioned
    - next_steps: Action items
    """
)
```

### Interview Processing

```python
result = pipeline.run(
    file_path=Path("interview.mp4"),
    user_requirements="""
    Extract interview information:
    - candidate_name: Full name of interviewee
    - position: Role being interviewed for
    - key_skills: Technical skills mentioned
    - experience_years: Years of experience
    - strengths: Positive points
    - concerns: Any red flags or concerns
    """
)
```

### Voice Memos

```python
result = pipeline.run(
    file_path=Path("voice_memo.m4a"),
    user_requirements="""
    Extract notes:
    - topic: Main subject
    - key_points: Important items mentioned
    - reminders: Things to remember
    - dates: Any dates or deadlines mentioned
    """
)
```

## Supported Formats

| Type | Formats | Requirements |
|------|---------|--------------|
| Audio | mp3, wav, m4a, ogg | None |
| Video | mp4, avi, mov, mkv | FFmpeg required |
| Large files | Any (>25MB) | FFmpeg for compression |

| Variable | Required | Description |

| `AZURE_ENDPOINT` | Azure only | Azure OpenAI endpoint |
| `OPENAI_API_KEY` | OpenAI only | Standard OpenAI API key |
