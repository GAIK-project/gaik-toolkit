## Software Components

Software components are reusable, low-level capabilities. You can use them
individually or compose them into larger pipelines.

See also: [No-Code Assets](/toolkit/no-code-assets) for prompt templates and packaged skills.

<Callout type="info">
Use software components when you need fine-grained control over parsing,
transformation, validation, and orchestration.
</Callout>

| Scope | What you control | Typical outcome |
| --- | --- | --- |
| Component-level | Parser/model/settings per step | Flexible custom workflows |
| Module-level | A full predefined pipeline | Faster implementation |

### Data Extraction

Converts unstructured text into validated structured output. The workflow is:
requirements -> schema -> extraction.

Main features:
- Dynamic schema generation from plain-language requirements
- Type-safe extraction outputs
- Reusable schema for repeated workloads

Examples show invoice-like extraction and batch extraction across multiple
documents.

- **Implementation code**: [implementation_layer/src/gaik/software_components/extractor](https://github.com/GAIK-project/gaik-toolkit/tree/main/implementation_layer/src/gaik/software_components/extractor)
- **Usage examples**: [implementation_layer/examples/software_components/extractor](https://github.com/GAIK-project/gaik-toolkit/tree/main/implementation_layer/examples/software_components/extractor)

### Document Parsing

Parses documents into normalized text/markdown for extraction and indexing.

Main features:
- Vision-based and local parsing options
- Markdown-ready output
- Multi-page processing support

Examples cover parser selection and PDF-to-markdown style conversions.

- **Implementation code**: [implementation_layer/src/gaik/software_components/parsers](https://github.com/GAIK-project/gaik-toolkit/tree/main/implementation_layer/src/gaik/software_components/parsers)
- **Usage examples**: [implementation_layer/examples/software_components/parsers](https://github.com/GAIK-project/gaik-toolkit/tree/main/implementation_layer/examples/software_components/parsers)

### Transcribing

Transcribes audio/video into raw text and optionally enhanced transcript text.

Main features:
- Whisper-based transcription pipeline
- Optional transcript enhancement
- Chunked processing for longer recordings

Examples include direct file transcription and context-guided transcript runs.

- **Implementation code**: [implementation_layer/src/gaik/software_components/transcriber](https://github.com/GAIK-project/gaik-toolkit/tree/main/implementation_layer/src/gaik/software_components/transcriber)
- **Usage examples**: [implementation_layer/examples/software_components/transcriber](https://github.com/GAIK-project/gaik-toolkit/tree/main/implementation_layer/examples/software_components/transcriber)

### Document Classification

Assigns documents to predefined classes to support routing and filtering.

Main features:
- Multi-class categorization
- Confidence-scored predictions
- Standalone pre-processing capability

Examples show folder-level classification and confidence-based review.

- **Implementation code**: [implementation_layer/src/gaik/software_components/doc_classifier](https://github.com/GAIK-project/gaik-toolkit/tree/main/implementation_layer/src/gaik/software_components/doc_classifier)
- **Usage examples**: [implementation_layer/examples/software_components/classifier](https://github.com/GAIK-project/gaik-toolkit/tree/main/implementation_layer/examples/software_components/classifier)

### RAG Components

Provides composable building blocks for retrieval-augmented generation.

Main features:
- Parser, embedder, vector store, retriever, and answer generator
- Metadata-preserving chunking and retrieval
- Optional reranking and citation-aware answering

Examples include parser-to-retriever chains and complete RAG Q&A flows.

- **Implementation code**: [implementation_layer/src/gaik/software_components/RAG](https://github.com/GAIK-project/gaik-toolkit/tree/main/implementation_layer/src/gaik/software_components/RAG)
- **Usage examples**: [implementation_layer/examples/software_components/RAG](https://github.com/GAIK-project/gaik-toolkit/tree/main/implementation_layer/examples/software_components/RAG)
