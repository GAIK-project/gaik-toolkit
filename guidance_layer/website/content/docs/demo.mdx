## Software Modules

End-to-end pipelines demonstrating complete workflows from input to structured output. These modules combine multiple software components into single, production-ready solutions.

### Audio → Structured Data

Upload an audio or video file and define your field requirements in plain language. The module transcribes the content and extracts structured data in one unified pipeline, returning both the transcript and validated fields.

**Demonstrates:** Complete voice-to-data workflow combining transcription and intelligent extraction.

[Try it live →](https://gaik-demo.2.rahtiapp.fi/audio-structured)

### Document → Structured Data

Upload a PDF or Word document and specify what data you need to extract. The module parses the document to markdown and extracts structured fields according to your requirements, supporting both simple and complex layouts.

**Demonstrates:** End-to-end document processing with configurable extraction logic.

[Try it live →](https://gaik-demo.2.rahtiapp.fi/document-structured)

## Software Components

Individual building blocks that can be used standalone or combined into custom pipelines. Each component demonstrates a specific capability in the knowledge extraction and processing workflow.

### Extractor

Describe the fields you need in plain language, and the Extractor generates a schema and fills it from your source text. No code, no predefined templates — just natural language requirements converted into structured output.

**Key capability:** Schema-free structured extraction using natural language field definitions.

[Try it live →](https://gaik-demo.2.rahtiapp.fi/extractor)

![Extractor Demo](/demo-images/extractor.png)

---

### Document Parser

Transform PDFs and Word documents into clean, structured markdown. Choose between vision-based parsing for complex layouts or local parsing for speed. Tables, headings, and formatting are preserved.

**Key capability:** Multi-strategy document parsing with structure preservation.

[Try it live →](https://gaik-demo.2.rahtiapp.fi/parser)

![Parser Demo](/demo-images/parser.png)

---

### Document Classifier

Define custom categories in natural language and the classifier assigns each document to the most appropriate category using AI-powered semantic understanding.

**Key capability:** Zero-shot document classification with custom, user-defined categories.

[Try it live →](https://gaik-demo.2.rahtiapp.fi/classifier)

![Classifier Demo](/demo-images/classifier.png)

---

### Transcriber

Upload audio or video files and receive accurate transcriptions powered by OpenAI Whisper. Optional GPT-based enhancement cleans up the transcript for improved readability.

**Key capability:** High-quality speech-to-text with optional post-processing enhancement.

[Try it live →](https://gaik-demo.2.rahtiapp.fi/transcriber)

![Transcriber Demo](/demo-images/transcriber.png)

### RAG Builder

Upload document collections and build an intelligent Q&A system. The RAG Builder indexes your documents, enabling semantic search and contextual answer generation with source citations.

**Key capability:** Complete retrieval-augmented generation pipeline with persistent vector storage.

[Try it live →](https://gaik-demo.2.rahtiapp.fi/rag)

## Real-World Use Case Demos

Full application examples demonstrating how GAIK toolkit components solve specific business problems. These demos showcase complete user experiences from data capture to structured report generation.

### Incident Reporting

Field workers report safety incidents or equipment issues via voice recording or text input. The system automatically transcribes, extracts structured incident fields, and generates a formatted report — reducing manual data entry and ensuring consistent documentation.

**Business value:** Faster incident capture, improved compliance, reduced administrative overhead.

[Try it live →](https://gaik-demo.2.rahtiapp.fi/incident-report)

![Incident Reporting Demo](/demo-images/incident.png)

---

### Construction Diary

Site workers record daily activities, observations, and progress notes via voice or text. The AI extracts structured information (tasks completed, materials used, weather conditions, issues) and generates standardized diary entries.

**Business value:** Streamlined site documentation, improved project tracking, audit-ready records.

[Try it live →](https://gaik-demo.2.rahtiapp.fi/diary)

![Construction Diary Demo](/demo-images/diary.png)

---

### Video Transcription & Subtitles

Upload a lecture, podcast, or training video and receive accurate transcripts with synchronized SRT and VTT subtitle files. The pipeline processes hours of audio in parallel, supports Finnish and other languages, and handles large files automatically.

**Business value:** Accessible video content, searchable transcripts, compliance with captioning requirements.

[Try it live →](https://gaig-demo.2.rahtiapp.fi/dental-transcription) · [Read more →](/docs/use-cases/transcription-captioning-translation)

![Transcription Demo](/demo-images/dental-transcription.png)

---

### Semantic Video Search

Search across an entire video library by describing what you're looking for in plain language. The system returns timestamped results so you can jump directly to the relevant moment — no more scrubbing through hours of footage.

**Business value:** Instant access to specific knowledge within video libraries, improved learning efficiency.

[Try it live →](https://gaik-demo.2.rahtiapp.fi/video-search) · [Read more →](/docs/use-cases/semantic-video-search)

![Video Search Demo](/demo-images/video-search.png)

## No-Code Assets

Ready-to-use prompt templates and agent skills that enable rapid deployment without custom development. Paste a prompt directly into ChatGPT, Claude.ai, or Gemini, or install an agent skill into Claude Desktop — no coding required.

### Prompt Templates

Each prompt pack includes task instructions, field definitions, business rules, and sample data for immediate testing. Adapt to your domain by editing field names and allowed values.

| Prompt pack | Description |
|-------------|-------------|
| **Construction diary creation** | Extract structured daily diary fields from a site supervisor's voice recording |
| **Incident report writing** | Extract structured incident and safety observation fields from a spoken report |
| **Purchase-order processing** | Extract and price purchase order line items from single or multi-document PDFs |
| **Safety observation reporting** | Extract structured safety observation fields from a voice note or typed description |

**Browse all templates:** [implementation_layer/no-code-assets/prompts](https://github.com/GAIK-project/gaik-toolkit/tree/main/implementation_layer/no-code-assets/prompts)

---

### Agent Skills

Fully packaged, ready-to-run solution bundles for Claude Desktop. Each skill includes prompts, reference files, sample data, and workflow artifacts — everything needed for operational deployment.

| Agent skill | Description |
|-------------|-------------|
| **Construction diary creation** | Voice-to-diary workflow with configurable schema and export |
| **Incident report writing** | Safety observation capture with structured report output |
| **Purchase-order processing** | End-to-end PO extraction, BOM matching, pricing, and sales order generation |
| **Report writing skill** | Structured report generation from notes, documents, or voice input |

**Browse all skills:** [implementation_layer/no-code-assets/agent-skills](https://github.com/GAIK-project/gaik-toolkit/tree/main/implementation_layer/no-code-assets/agent-skills)
