# Extraction Requirements: MaintenanceTicket

## Task
You are extracting structured maintenance ticket fields from a Finnish-language
voice recording transcript. The technician has reported a facility fault verbally.
Your job is to populate a `MaintenanceTicket` object from the transcript.

**Language note:** The transcript is in Finnish. Field values in the output must
be in Finnish unless the field is a controlled enum (e.g. `urgency`) — those
must always be output in English as specified below.

---

## Output Format
Return a single JSON object with exactly the fields listed below.
- Set a field to `null` if the information was not stated or cannot be reliably
  extracted from the transcript.
- Do **not** invent, infer, or guess values. If a technician said something
  ambiguous, prefer `null` and flag the field in `uncertain_fields`.
- For required fields (`location`, `fault_description`, `urgency`): if the value
  is null, the field name **must** appear in `uncertain_fields`.

---

## Fields

### `reporter_name` — string | null — Optional
Extract if the technician introduces themselves. Do not extract job titles.

### `asset_identifier` — string | null — Optional
Asset tag, equipment number, or descriptive name (e.g. "pumppuyksikkö P-12",
"ilmanvaihtokone IV-03"). Extract verbatim.

### `location` — string | null — **Required**
Building, floor, room, corridor, or area. Finnish cues: "rakennuksessa",
"kerroksessa", "huoneessa", "käytävällä", "konehuoneessa".
Null → add "location" to `uncertain_fields`.

### `fault_description` — string | null — **Required**
Full fault description in the technician's own Finnish words. Capture symptoms,
affected parts, observable signs. Finnish fault cues: "viallinen", "rikki",
"vuotaa", "ei toimi", "ylikuumenee", "jumissa".
Null → add "fault_description" to `uncertain_fields`.

### `urgency` — "low" | "medium" | "high" | null — **Required**
Always output in English. Mapping:
- kiireellinen / heti / välittömästi / kriittinen → "high"
- normaali / kohtuullinen / ei kiireellinen → "medium"
- matala / ei kiireinen / sopii odottaa → "low"
If not stated, apply contextual reasoning (safety hazard/total failure → "high";
performance degradation → "medium"; cosmetic issue → "low").
Null → add "urgency" to `uncertain_fields`.

### `observation_date` — date (YYYY-MM-DD) | null — Optional
Finnish cues: "tänään", "eilen", "maanantaina", specific dates like "15.7."

### `observation_time` — string (HH:MM) | null — Optional
Finnish cues: "klo", "kello". Convert 12-hour to 24-hour.

### `actions_taken` — list[string] | null — Optional
Immediate actions already taken, each as a short Finnish sentence.
Finnish cues: "suljin", "sammutin", "ilmoitin", "eristin".
If none → null (not []).

### `uncertain_fields` — list[string] | null — Optional*
Field names that could not be reliably extracted, in snake_case.
Required when any required field is null.

---

## Handling Rules
1. Never invent values — if absent, use null.
2. Required fields null → must appear in uncertain_fields.
3. urgency enum is strict: only "low", "medium", "high".
4. Free-text fields (location, fault_description, actions_taken) stay in Finnish.
5. Dates → YYYY-MM-DD; times → HH:MM.
6. No hallucination — extract only what is in this transcript.
