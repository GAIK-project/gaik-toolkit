## Task
Role-aware RAG assistant that answers employee questions over internal manufacturing policies, equipment manuals, and management documents with citations and enforced role-based access control.

Instead of manually searching across folders and binders, employees and managers ask questions in plain language and receive a direct, sourced answer in seconds. Every answer cites the exact document and page it came from, so users can verify the information instantly. Sensitive management documents remain invisible to general employees — the system enforces this automatically, not by convention.

## Business need
**Current process:** Employees manually search across internal policies, equipment manuals, and management documents to find relevant information, which is slow and can lead to incomplete or unsupported answers.

**Pain points:**
- Manual document search is slow and time-consuming
- Employees may overlook the applicable source document
- Risk of incomplete or unsupported answers
- No enforcement of document access boundaries between roles

## Proposed solution
RAG-based assistant that answers employee questions using the document collection, provides citations to the supporting source, and enforces role-based access so restricted documents are never retrieved or disclosed to unauthorized employees.

The assistant replaces manual searching with a single natural-language question: it reads and indexes the document collection, retrieves only the most relevant passages for each user's role, and generates a concise answer with precise citations. Role-based access is enforced at the retrieval stage — no restricted chunk ever enters the model's context for an unauthorised user, eliminating leakage through both answers and citations. When no authorised source supports a question, the assistant says so explicitly rather than speculating.

## Users and stakeholders
- **Intended users:** employee, manager
- **Reviewers:** _none_
- **Stakeholders:** employees, managers, knowledge_owners

## Knowledge object
- **Input artifacts:** employee_travel_policy.pdf, mx200_maintenance_manual.pdf, project_aurora_pricing_strategy.pdf, access_manifest.json, query_set.json, poc_input_bundle.json
- **Target output artifacts:** rag_answer_records_json

The central knowledge object is the **internal document collection** — a set of role-classified PDFs that is transformed from static files requiring manual search into a queryable, access-controlled knowledge base that returns grounded, cited answers per user role.

## Expected benefits
- Faster access to reliable internal knowledge
- Traceable answers via source citations
- Enforced access boundaries with no content leakage across roles

## Success criteria
- Employees find reliable answers faster than manual search
- Answers are verifiable through document citations
- Employees never receive content outside their authorized role
- System correctly refuses to answer from unauthorized content

## Evaluation focus
Four role-tagged queries (Q01-Q04) with exact expected access decisions, answer content, and citation pairs. Q01 (employee, Helsinki hotel limit): access=allowed, EUR 180/night + Finance Director approval, cite [employee_travel_policy.pdf, 3]. Q02 (employee, MX-200 filter): access=allowed, 250h inspection + 1000h or 1.8bar replacement, cite [mx200_maintenance_manual.pdf, 3] and [mx200_maintenance_manual.pdf, 4]. Q03 (employee, Project Aurora ceiling): access=denied, empty citations, no 12%/22%/CFO details. Q04 (manager, Project Aurora ceiling and approver): access=allowed, 12% ceiling + CFO written approval, cite [project_aurora_pricing_strategy.pdf, 3].

## Risks and constraints
- Hallucinated answers not grounded in retrieved content
- Fabricated or incorrect citations
- Retrieval of restricted chunks for unauthorized roles
- Leakage of restricted content through answer text or citations
- Stale documents producing outdated answers
- System returning speculative answer when no authorized source supports the query
