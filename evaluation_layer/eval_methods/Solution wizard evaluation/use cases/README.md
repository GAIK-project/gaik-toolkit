# Use Cases

This folder contains evaluation use cases for the GAIK Solution Wizard. Each use case focuses on a different business scenario and includes generated outputs, supporting files, and run artifacts used to evaluate the solution.

## Available Use Cases

| Use Case | Description |
| --- | --- |
| `UC01_audio_incident_evaluation` | Evaluates an audio-based incident workflow, including transcription, interpretation, and incident analysis outputs. |
| `UC02_purchase_order_evaluation` | Evaluates purchase order processing, extraction, validation, and related business document handling. |
| `UC03_document_rag_evaluation` | Evaluates document-based retrieval augmented generation workflows using source documents and generated answers. |
| `UC04_multi_source_report_evaluation` | Evaluates report generation using multiple input sources, synthesized insights, and supporting evidence. |

## Folder Structure

Each use case folder may include:

- input files or source documents
- generated packages
- run outputs
- refinement attempts
- evaluation artifacts
- proof-of-concept files

The exact structure may vary by use case depending on the workflow being evaluated.
