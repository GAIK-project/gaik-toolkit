## Task
Extract structured header and line-item data from customer purchase order PDFs and produce reviewer-verified ERP-compatible JSON records.

The system reads customer purchase order PDFs — whether digitally created or scanned — and automatically fills in the corresponding ERP record fields: order reference, delivery date and address, vendor number, and all ordered line items with their material grades, dimensions, quantities, and product forms. A human reviewer checks the result against the original document before the record is released for ERP entry.

## Business need
**Current process:** Order-processing employees manually inspect customer purchase orders and enter header and line-item information into the ERP system.

**Pain points:**
- Manual data entry is slow and error-prone
- Complex table layouts and multi-page rows increase transcription difficulty
- Product code and unit omissions cause downstream ERP errors
- No systematic verification step before ERP transfer

## Proposed solution
Automatically extract structured PO data using AI, present the result alongside confidence information and the original PDF for reviewer verification, and export an approved ERP-compatible JSON record.

Instead of retyping every field by hand, the order-processing employee uploads the PO PDF and the system reads it using a vision AI model that handles scanned pages, complex multi-column tables, and rows split across pages. The extracted record is immediately presented to the reviewer alongside per-field confidence scores and the original document, so errors can be spotted and corrected before anything reaches the ERP. Only reviewer-approved records proceed — eliminating the risk of unverified data entering the system.

## Users and stakeholders
- **Intended users:** order_processing_employees
- **Reviewers:** procurement_reviewer, order_processing_reviewer
- **Stakeholders:** order_processing_employees, procurement_reviewers, procurement_management

## Knowledge object
- **Input artifacts:** customer purchase order PDFs (native and scanned)
- **Target output artifacts:** ERP-compatible structured JSON record per purchase order

The central knowledge object is the **purchase order** — a structured commercial document received from customers — which is transformed from an unstructured PDF (including scanned images with complex tables) into a validated, machine-readable `PurchaseOrderERPRecord` JSON object ready for direct ERP entry.

## Expected benefits
- Faster order entry
- More consistent ERP records
- Fewer transcription and omission errors

## Success criteria
- Faster and more consistent ERP data preparation
- Fewer manual transcription and omission errors
- Every record is reviewer-verified before ERP transfer

## Risks and constraints
- Loss of complex table structure during extraction
- Merging of distinct line items
- Missing rows that continue across pages
- Alteration of product codes or leading zeros
- Dropping units of measure
- Inventing (hallucinating) field values
- Transferring an unreviewed record to the ERP
