## Task
Extract structured header and line-item data from customer purchase order PDFs and produce an ERP-compatible JSON record for reviewer-verified entry.

When a customer sends a purchase order by email or file transfer, an order-processing employee currently has to open the PDF, read each field and line item, and type all the information into the ERP system by hand. This solution automates that reading and typing step: the AI processes the PDF and produces a ready-to-verify ERP record in seconds. The employee's job shifts from data entry to reviewing the AI's output before approving it for transfer.

## Business need
**Current process:** Order-processing employees inspect customer purchase orders received as PDFs and manually enter header and line-item information into the ERP system. A procurement or order-processing reviewer then verifies the generated record before it is transferred.

**Pain points:**
- Time-consuming manual data entry from diverse PO formats
- Transcription errors (wrong quantities, prices, product codes, leading zeros)
- Omission errors (missed fields, rows, or units)
- Handling format variety across customers

## Proposed solution
AI-powered extraction of PO header and line-item fields from PDF documents into a structured ERP-compatible JSON record, followed by reviewer verification before transfer.

The solution uses a vision-capable AI model that reads purchase order PDFs as images, preserving table structure, merged cells, and cross-page rows that text-based parsers routinely lose. It extracts every header and line-item field into a structured record that strictly follows the agreed schema — leading zeros intact, article codes case-preserved, dates normalised, and absent optional fields set to null rather than invented. A built-in LLM judge pre-screens each record for hallucinated or unsupported values before the record reaches the reviewer, so the reviewer spends their time on judgement rather than error-hunting.
