We are a manufacturing company that prepares a quarterly supplier-performance report for procurement management. Today a procurement analyst manually combines a KPI spreadsheet, a supplier quality-audit report, procurement meeting notes, and a delivery-incident log. The work is slow, calculations and wording can become inconsistent, and report claims are difficult to trace back to their sources. We want a GAIK-based solution that synthesizes these mixed sources into a structured, evidence-grounded report with source references. A procurement manager must review the draft before it is released.
