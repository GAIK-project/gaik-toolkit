## Task
Synthesise KPI spreadsheet, quality audit, meeting notes, and delivery-incident log into a structured, evidence-grounded Markdown report with inline citations and an evidence index for procurement management review.

Each quarter, the procurement team must assess how well its key suppliers have been performing — reviewing delivery reliability, quality audit results, incident data, and agreed actions from multiple documents. This solution reads the four raw source files and automatically drafts a sourced, structured report that is ready for a manager's review, replacing the time-consuming manual synthesis work entirely.

## Business need
**Current process:** A procurement analyst manually combines a KPI spreadsheet, a supplier quality-audit report, procurement meeting notes, and a delivery-incident log into a quarterly supplier-performance report.

**Pain points:**
- Manual process is slow and labour-intensive
- Calculations and wording can become inconsistent across report versions
- Factual claims are difficult to trace back to their source documents
- Conflicts between sources (e.g. spend discrepancies) may go undetected or undisclosed

## Proposed solution
Use GAIK MultiSourceReportGenerator to synthesise four mixed-format sources (xlsx, pdf, md, csv) into a structured, evidence-grounded Markdown report with inline source citations and an evidence index. A procurement manager reviews every draft before release.

The AI reads and cross-references all four source files simultaneously, so the report is produced in minutes rather than hours. All KPI figures are calculated directly from the authoritative workbook, conflicts between sources are flagged explicitly (e.g. the EUR 410,000 meeting-note approximation versus the exact EUR 405,000 workbook figure), and every material claim carries an inline source citation — making the report traceable and consistent by design rather than by effort.
