# Q2 2026 Supplier Performance Report -- Multi-Source Synthesis

Proof of Concept generated by GAIK Solution Configuration Wizard V2.

---

## What this PoC does

A procurement analyst runs this pipeline with four quarterly source documents.
MultiSourceReportGenerator (agentic mode, strict review) synthesises them into:

- **output/report.md** -- "Q2 2026 Supplier Performance Report": six-section Markdown
  draft with inline [source_file] citations and a KPI table calculated from the workbook.
- **output/evidence_index.json** -- audit trail listing every source file processed.

The report is a **DRAFT**. It must be reviewed and approved by the procurement manager
before it is released. The PoC never produces an approved report.

## Running the PoC

```
python run_poc.py --input <path-to-poc_input_bundle.json>
```

Example (using the supplied fixtures):

```
python run_poc.py --input C:\Users\h02317\Downloads\fixtures\poc_input_bundle.json
```

The bundle resolves all source file paths relative to its own directory.

---

## Input bundle format

The bundle is a JSON file with this structure:

```json
{
  "source_files": [
    "poc_input/sources/supplier_kpis_q2_2026.xlsx",
    "poc_input/sources/nordic_components_quality_audit.pdf",
    "poc_input/sources/procurement_meeting_notes_q2_2026.md",
    "poc_input/sources/delivery_incidents_q2_2026.csv"
  ],
  "report_spec": "poc_input/report_spec.json",
  "sample_report": "poc_input/report_template.md"
}
```

All paths are resolved relative to the directory that contains the bundle file.

## Expected output

**output/report.md** must contain:

| Requirement | Detail |
|---|---|
| Title | "Q2 2026 Supplier Performance Report" |
| Sections | Executive Summary; KPI Overview; Supplier Findings; Quality and Delivery Risks; Actions and Owners; Source References |
| KPI table | Overall 299/91.6%/26,550/2.0%/EUR 867,000; Nordic 135/85.2%/13,500/3.1%/EUR 405,000; Baltic 97/96.9%/9,700/1.0%/EUR 194,000; Alpine 67/97.0%/3,350/0.6%/EUR 268,000 |
| Citations | All material claims cite exact filename in [source_file] format |
| Disclosure | EUR 410,000 (meeting note approximation) vs EUR 405,000 (workbook authoritative) |
| Sources | All four source filenames listed in Source References |

**output/evidence_index.json** must be parseable JSON.

Acceptance is evaluated against `fixtures/expected_report_results.json` (facts F01-F10).

## Adjusting the PoC

| What to change | Which file |
|---|---|
| Section instructions | Edit report_spec.json in the bundle and re-run |
| Model or temperature | config.yaml (models: generation/review/temperature/reasoning_effort) |
| Azure endpoint / API key | .env |
| Evaluation | evals/run_basic_eval.py |
