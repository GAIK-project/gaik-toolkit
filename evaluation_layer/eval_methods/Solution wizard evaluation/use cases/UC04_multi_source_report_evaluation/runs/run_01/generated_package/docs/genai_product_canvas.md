## Task
GAIK synthesises four quarterly procurement documents (KPI spreadsheet, quality-audit report, meeting notes, incident log) into a structured, cited Markdown report with evidence index; a procurement manager reviews and approves the draft before release.

Every quarter, a procurement analyst gathers four internal documents — a KPI workbook, a quality-audit report, meeting notes, and a delivery-incident log — and hands them to GAIK. The system reads all four, calculates KPI metrics, synthesises the evidence into a structured six-section report with inline source citations, and writes an audit trail that maps every claim back to its source file. A procurement manager then reviews the draft before it is released to stakeholders.

## Business need
**Current process:** A procurement analyst manually combines a KPI spreadsheet, a supplier quality-audit report, procurement meeting notes, and a delivery-incident log each quarter to produce the supplier performance report for procurement management.

**Pain points:**
- Slow manual assembly of heterogeneous source documents
- Inconsistent calculations across report versions
- Inconsistent wording and terminology
- Report claims are difficult to trace back to source documents

## Proposed solution
MultiSourceReportGenerator synthesises all four sources into a structured, cited Markdown report (output/report.md) and evidence index (output/evidence_index.json). A mandatory procurement-manager review gate prevents release of unapproved drafts.

By delegating document parsing, KPI calculation, and narrative drafting to MultiSourceReportGenerator, the analyst no longer assembles the report manually — the pipeline reads all four sources in a single run and drafts each section from the same evidence base, eliminating calculation drift and wording inconsistencies between versions. Every material claim is cited to its exact source file (e.g. [supplier_kpis_q2_2026.xlsx]), and data conflicts such as the EUR 410,000 meeting-note approximation versus the authoritative EUR 405,000 workbook figure are surfaced explicitly rather than silently resolved. The mandatory manager-review gate ensures no draft reaches stakeholders before it is approved.
