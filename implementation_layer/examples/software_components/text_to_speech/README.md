# Text-to-Speech Example

This example shows how to generate speech audio from text using the `TextToSpeech` software component.

## Run

```bash
python implementation_layer/examples/software_components/text_to_speech/text_to_speech_example.py
```

## Output

The example saves a generated `.mp3` file into `implementation_layer/examples/software_components/text_to_speech/output/`.
