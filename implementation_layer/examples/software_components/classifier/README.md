# Document Classifier Example

This example demonstrates how to use the Document Classifier component to classify documents into custom categories using natural language descriptions.

## Files

- `classification_example.py` - Complete example showing document classification with user-defined categories

## What This Example Shows

- How to define custom classification categories in plain language
- How to classify documents without predefined schemas
- How to use AI-powered semantic understanding for document categorization

## Usage

```bash
python classification_example.py
```
