# GenAI Product Canvas

For use case definition, the toolkit provides a **GenAI product canvas**, which helps teams structure the problem, clarify the expected value, identify users and stakeholders, and define how GenAI will be used in practice. 

# Reference GenAI product descriptions

For each generic use case (for example, incident reporting), the toolkit also includes **reference GenAI product descriptions** based on this canvas. These descriptions serve as concrete examples that organizations can adapt to their own context.
